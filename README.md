What simulation is the User running?

User will see four areas on their screen: a point-and-click simulation canvas, a user interface with all controls, a dynamic free body diagram for the selected node, and an energy graph for the whole system.

Things the User can change in the simulation?

User must use the mouse to click positions for nodes in the canvas; nodes will not be created if the mouse overlaps with a pre-existing node or if the mouse is out of the simulation box (which is denoted by a dark grey square). The program will automatically generate springs between n most recently created nodes.
